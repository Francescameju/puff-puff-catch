# Puff-Puff Catch

A small browser game for [start.ng](https://start.ng). Mama's frying is flying: catch the falling puff-puff as your own start.ng character, grab the golden ones for +5, and dodge the pepper.

- Move: arrow keys or A / D, or drag with finger or mouse
- 3 lives. Catching pepper costs a life; missing a puff-puff breaks your streak.
- Leaderboard: puff-puffs caught, then best streak (see `startng.json`)

Plain HTML, CSS and JavaScript. No build step.
